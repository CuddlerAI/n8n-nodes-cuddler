# n8n-nodes-cuddler

Cuddler community node for [n8n](https://n8n.io): generate video, images, speech and music in your workflows with a [Cuddler Platform](https://platform.cuddler.ai) API key.

## Status

Scaffold only. The node source lands through pull requests; nothing is published to npm yet.

## Layout (planned)

- `nodes/` — the Cuddler node
- `credentials/` — Cuddler Platform API key credential
- `package.json` — `n8n-nodes-cuddler`, keyword `n8n-community-node-package`, no runtime dependencies
